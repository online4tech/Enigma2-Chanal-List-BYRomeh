طريقة التثبيت

التثبيت عبر USB

  1. قم بتحميل الملف من الرابط أعلاه.
  2. ضع الملف داخل USB أو احفظه على الكمبيوتر.
  3. أدخل USB في جهاز الاستقبال.
  4. من قائمة الإعدادات اختر القنوات / الاستيراد / التحديث.
  5. حدد الملف ثم أعد التشغيل أو اعمل الفحص.

التثبيت عبر FTP

  1. تأكد من اتصال الجهاز بالشبكة.
  2. استخدم برنامج FTP مثل FileZilla.
  3. انقل الملف إلى المسار المناسب داخل النظام.
  4. أعد التشغيل أو أعد الفحص بعد النقل.
  5. تأكد من ظهور القنوات بشكل صحيح.

التثبيت عبر Telnet / SSH

  1. تسجيل الدخول إلى الجهاز عبر Telnet أو SSH.
  2. تحميل الملف داخل مجلد مناسب.
  3. استخدم الأمر المناسب لفك الضغط أو النقل.
  4. أعد التشغيل أو استخدم Re-scan.
  5. تأكد من ظهور القائمة بشكل صحيح.

طرق النقل السريعة

USB

الأسهل والأسرع للمستخدمين العاديين.

  • سريع ومباشر
  • لا يحتاج إلى شبكة
  • مناسب لمعظم الأجهزة

FTP

مناسب للمستخدمين الذين يفضلون النقل عبر الشبكة.

  • نقل سلس
  • مناسب للملفات الكبيرة
  • مرن ومريح

Telnet / SSH

حل متقدم ويستخدم في التعديلات والوضع اليدوي.

  • تحكم كامل
  • مناسب للمستخدمين المتقدمين
  • خيارات أكثر
